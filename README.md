# UnitaryScripts
A collection of focused, single-purpose scripts derived from larger security tools. Each script performs a specific task independently.

## Example Case
The [PrivescCheck](https://github.com/itm4n/PrivescCheck) tool performs a wide range of security checks on Windows systems. However, running the entire tool can trigger security solutions, and its extensive codebase can make it difficult to understand exactly what each check does.

This repository aims to break down these checks into focused, single-purpose scripts. Each script performs a specific task, making the underlying checks easier to understand and allowing auditors to run them individually when needed.
